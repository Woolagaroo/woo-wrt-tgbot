# 🤖 OpenWrt Telegram Bot (woo-wrt-tgbot)

![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)

Многофункциональный Telegram-бот для удаленного управления роутерами на базе **OpenWrt**.

---
## ⚠️ ВАЖНОЕ СИСТЕМНОЕ ТРЕБОВАНИЕ

Для корректного отображения таблиц без искажения интерфейса, ширина экрана вашего смартфона должна быть **не менее 416 dp / pt**. 

Если у вас стандартный экран (360–390 dp), строки таблиц будут переноситься, что нарушит их читаемость.

### 🤖 Как настроить на Android:
1. Перейдите в **Настройки** → **О телефоне** и нажмите на **«Номер сборки»** 7 раз, чтобы активировать *Режим разработчика*.
2. Вернитесь в **Настройки** → **Система** (или *Дополнительно*) → **Для разработчиков**.
3. Найдите пункт **«Минимальная ширина»** (Smallest Width) и измените значение по умолчанию на **416** (или выше).

### 🍏 Как это работает на iOS (iPhone):
* На моделях **iPhone Plus** и **Pro Max** (14/15/16) интерфейс отображается **идеально по умолчанию** (их ширина 428–440 pt).
* На базовых моделях iPhone и версиях Pro (ширина 390–393 pt) строки будут разрушать форматирование из-за ограничений системы iOS, где нельзя вручную задать точную ширину в dp.

## 🌟 Основные возможности

### 📡 Управление Wi-Fi
*   **Радиомодули**: Смена канала, ширины канала (HT/VHT/HE), мощности сигнала (dBm) и стандарта (b/g/n/ac/ax) «на лету».
*   **Точки доступа (AP)**: Создание, редактирование и удаление сетей.
*   **Гостевые сети**: Автосоздание изолированной сети с собственной подсетью, DHCP и Firewall.
*   **Клиент (STA)**: Подключение роутера к внешней Wi-Fi сети. Авто-откат при потере соединения.

### 🚦 Ограничение скорости (требуется предустановленный пакет Bandix: https://github.com/timsaya/openwrt-bandix/releases, https://github.com/timsaya/luci-app-bandix/releases)
*   **Гибкое лимитирование**: Установка ограничений скорости (Download/Upload) для конкретных устройств.
*   **Расписание**: Настройка лимитов по дням недели и времени действия.
*   **Профили**: До 5 профилей ограничений на одно устройство.
   
### ⚙️ Управление службами и Автозапуском
*   **Полный контроль** над системными службами OpenWrt (init.d). Просмотр статуса, запуск, остановка, перезапуск, а также включение и отключение автозагрузки прямо из Telegram.

### 🌐 Сеть, Безопасность и Устройства
*   **Блокировка MAC**: Мгновенная блокировка/разблокировка клиентов.
*   **Фиксация IP**: Назначение статических IP-адресов (dhcp host) и снятие фиксации.
*   **Новые устройства**: Уведомления о новых устройствах в сети с возможносью блокировки несанкционированных.
*   **Отслеживание**: выбранных MAC-адресов для уведомлений о подключении/отключении их от сети.
*   **Wake-on-LAN**: Пробуждение устройств по сети.
*   **Трафик**: Мониторинг трафика по устройствам за день/неделю/месяц. (необходим пакет bandix с включенным мониторингом трафика)

### 💻 Терминал и Файловый менеджер
*   **`/exec`**-сессия. Поддерживает переменные окружения, пайпы, выполнение скриптов и длительные команды.
*   **Проводник**: Встроенный файловый менеджер с возможностью просмотра, переименования, копирования, удаления, скачивания и загрузки файлов. Распаковка архивов и установка пакетов  прямо из Telegram.

### 📊 Мониторинг, Журналы и События
*   **Журнал событий**: Умный парсер логов. Классифицирует события. Позволяет выгружать логи за период 6-72ч.
*   **Автоматические уведомления** о критических событиях в логах с возможностью добавления паттернов для скрытия различных инфо событий попадающих в категорию ошибок.
*   **Монитор RAM/Температуры**: Автоматические уведомления при перегреве CPU/Wi-Fi или нехватке ОЗУ (с настраиваемыми порогами и cooldown).
*   **Статус системы**: Просмотр текущей загрузки CPU, свободного места и температуры.
*   **Speedtest**: Замер скорости интернета.

## 🛠 Требования

*   **ОС**: OpenWrt 21.02+ (или совместимые: ImmortalWrt, LEDE).
*   **Архитектура**: Любая (MIPS, ARM, x86).
*   **ОЗУ**: **Не менее 64 МБ**.
*   **Обязательные пакеты**: `bash`, `curl`, `jq`, `gawk`, `iwinfo`, `hostapd-utils`, `flock`, `procps-ng-pkill`, `sed`, `coreutils-timeout`, `coreutils-stat`, `coreutils-du`, `findutils`.
*   **Опциональные пакеты**: `mhz` (для определения частоты cpu),`sexpect` (для терминала), `etherwake` (для WOL), `speedtestcpp` (для Speedtest).

## 🔑 Подготовка: Токен и Chat ID

Для работы бота вам понадобятся два обязательных параметра: **BOT_TOKEN** (уникальный ключ вашего бота) и **CHAT_ID** (ваш цифровой ID в Telegram, чтобы бот знал, кому отвечать и не пускал посторонних).

### 1. Как получить BOT_TOKEN
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте ему команду `/newbot`.
3. Придумайте имя бота (например, `My OpenWrt Bot`) и его username (обязательно должен заканчиваться на `bot`, например `my_openwrt_bot`).
4. В ответ BotFather пришлет вам сообщение с токеном вида: 
   `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`
5. **Скопируйте и сохраните этот токен.** Никому его не передавайте, так как он дает полный контроль над ботом.

### 2. Как получить CHAT_ID
1. В Telegram найдите бота **[@userinfobot](https://t.me/userinfobot)** (или **[@getmyid_bot](https://t.me/getmyid_bot)**).
2. Нажмите `/start`.
3. Бот пришлет ваше цифровое значение `Id` (например, `987654321`). Это и есть ваш **CHAT_ID**.
4. **Важно:** Перед первым запуском бота на роутере, *обязательно* найдите своего нового бота (созданного в BotFather) и нажмите в нем кнопку **`/start`**. Иначе Telegram заблокирует отправку сообщений от бота вам.

## 🚀 Быстрая установка

1. Подключитесь к роутеру по SSH (например, через PuTTY).
2. Выполните команду:

```bash
wget -O - https://github.com/Woolagaroo/woo-wrt-tgbot/releases/latest/download/install.sh | sh
```
